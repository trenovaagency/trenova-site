TRENOVA AGENCY | Multi-page website

START HERE
Open index.html to preview. No build step or installation is needed.

GITHUB PAGES
Unzip this archive. Upload every HTML file plus the assets and ugc folders to the repository root, keeping the folder structure unchanged. Enable GitHub Pages for the main branch/root if it is not already enabled. The entry page is index.html.

PAGES
index.html: Home
about.html: About
results.html: Our Campaigns, the single campaign listing
contact.html: Contact
campaign-*.html: One detail page for each campaign

LANGUAGE
Use EN / ع in the header. The language and theme selection are remembered in the same browser.

ASSETS
Fonts, scripts, images and UGC videos are included locally. Videos are compressed mobile-preview copies; external social post links require internet access.

CONTACT
The email and WhatsApp number are preserved from the supplied portfolio. Review them before publishing as the agency.
